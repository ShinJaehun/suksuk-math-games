# 쑥쑥수학게임

쑥쑥수학게임은 초등학교 수학 수업에 사용할 수 있는 브라우저 기반 수학 학습 게임 모음입니다. 놀면서 배우는 수학 학습을 목표로 합니다.

별도의 설치나 로그인 없이 태블릿이나 PC 웹 브라우저에서 바로 실행할 수 있습니다.

- 실행 주소: <https://shinjaehun.github.io/suksuk-math-games/>
- 저장소: <https://github.com/ShinJaehun/suksuk-math-games>

---

## 이 저장소에 대하여

- 처음에는 단순한 JavaScript 게임 모음으로 시작했지만, 현재는 초등 수학 수업에서 활용할 수 있는 수학 학습 게임 모음으로 방향을 정리했습니다.
- 현재 포함된 게임은 주로 4학년 수학의 평면도형의 이동 단원과 연결되어 있습니다. 학생들이 도형을 직접 움직이고, 돌리고, 방향과 경로를 생각하며 개념을 익힐 수 있도록 구성했습니다.
- 앞으로는 평면도형의 이동뿐 아니라 다른 학년과 단원의 수학 개념을 다루는 게임도 추가해 나갈 예정입니다.

---

## 왜 만들었나

수학 수업에서 평면도형의 이동을 지도할 때 학생들은 다음과 같은 부분에서 어려움을 겪을 수 있습니다.

- 도형이 위, 아래, 왼쪽, 오른쪽으로 이동했을 때 위치를 머릿속으로 떠올리기
- 도형을 돌리거나 방향을 바꾸었을 때 모양을 예상하기
- 이동 경로가 막히거나 겹칠 때 다른 방법을 찾기
- 규칙에 맞게 여러 단계의 이동을 계획하기
- 교과서나 학습지만으로는 충분히 조작해 보기 어려운 활동을 경험하기

쑥쑥수학게임은 이런 부분을 게임 형식으로 풀어 보려는 시도입니다. 학생들이 정답을 고르는 데서 끝나는 것이 아니라, 직접 움직이고 실패하고 다시 시도하면서 도형의 이동을 자연스럽게 경험하도록 설계했습니다.

## 개발 과정

쑥쑥수학게임은 처음부터 하나의 큰 게임 모음으로 시작한 프로젝트는 아닙니다.

처음에는 러시아워 게임을 별도 프로젝트로 만들면서 출발했습니다. 러시아워는 차량을 위아래 또는 좌우로 움직여 목표 차량을 탈출시키는 퍼즐로, 초등 수학에서 다루는 도형의 이동, 위치 변화, 공간 추론 활동과 연결하기 좋은 게임이었습니다. 이후 이 아이디어를 확장해, 러시아워 하나만이 아니라 여러 개의 작은 수학 게임을 모아 수업에서 활용할 수 있는 형태로 정리하기 시작했습니다. 닷링크, 테트리스, 파이프 드림 같은 게임은 모두 학생들이 손으로 조작하면서 방향, 이동, 회전, 연결, 경로를 생각하게 만든다는 공통점을 가지고 있습니다.

개발 과정에서는 ChatGPT를 개발 보조 도구로 활용했습니다. ChatGPT는 게임의 전체 방향을 대신 정하는 도구가 아니라, 게임 규칙을 코드 구조로 정리하고, JavaScript 로직을 나누며, 브라우저에서 안정적으로 동작하도록 리팩터링 방향을 점검하는 보조 도구로 사용했습니다.

## 개발 방향

쑥쑥수학게임의 방향은 단순한 미니게임 모음이 아니라, 수학 수업에서 바로 활용할 수 있는 교실용 수학 학습 게임 모음입니다.

현재는 4학년 평면도형의 이동 단원과 연결된 게임을 중심으로 정리하고 있으며, 앞으로는 다른 학년과 단원의 수학 개념을 다루는 게임도 추가할 예정입니다.

앞으로의 개선 방향은 다음과 같습니다.

- 각 게임에 학습 목표와 활동 안내 추가하기
- 현재 게임을 4학년 평면도형의 이동 단원과 더 명확하게 연결하기
- 다른 수학 단원으로 게임 주제 확장하기
- 태블릿 조작성을 더 안정적으로 개선하기
- 난이도별 레벨 구성 정리하기
- 수업 중 짧게 사용할 수 있는 활동 모드 추가하기
- 학생이 실패 후 다시 시도하기 쉬운 피드백 제공하기
